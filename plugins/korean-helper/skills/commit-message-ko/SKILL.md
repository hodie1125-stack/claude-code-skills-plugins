# 한국어 커밋 메시지 작성

1. `git diff --staged`로 스테이징된 변경을 확인합니다. 비어 있으면 `git diff`를 봅니다.
2. 아래 형식으로 작성합니다.

```
<타입>: <50자 이내 요약>

- 변경 이유와 핵심 내용을 글머리표로
- 한 줄에 하나씩
```

타입: `기능`, `수정`, `문서`, `리팩터`, `테스트`, `설정`

3. 요약은 "~추가", "~수정"처럼 명사형으로 끝냅니다.
4. 사용자가 요청하지 않으면 직접 커밋하지 말고 메시지만 제안합니다.
