# 한국어 인사말 작성

사용자가 인사말이나 자기소개 문구를 요청하면 다음 규칙을 따르세요.

1. 상황(회사, 모임, 이메일, 발표 등)을 먼저 파악합니다. 불분명하면 한 번만 물어봅니다.
2. **격식체(합니다체)** 와 **친근체(해요체)** 두 가지 버전을 제시합니다.
3. 각 버전은 3~5문장으로 짧게 작성합니다.
4. 마지막에 상황에 맞게 바꿔 쓸 수 있는 표현 2~3개를 덧붙입니다.
